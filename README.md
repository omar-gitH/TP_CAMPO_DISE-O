# REAGRO - Sistema de Gestión para Banco de Alimentos

REAGRO es una plataforma diseñada para optimizar la logística de rescate de alimentos frutihortícolas. El sistema conecta de forma eficiente a productores agrícolas, transportistas voluntarios y comedores comunitarios, garantizando la trazabilidad integral de la mercadería desde la quinta hasta su destino final.

## 🎯 Objetivo del Proyecto
El proyecto busca reducir el desperdicio de alimentos mediante la digitalización del circuito de donaciones, aportando herramientas de planificación agrícola y control logístico para la toma de decisiones.

## ⚙️ Módulos Principales
* **Gestión de Donaciones (RF01):** Registro detallado de excedentes productivos. Utiliza un modelo de cabecera-detalle para controlar lotes físicos, fechas de vencimiento y requerimientos de cadena de frío.
* **Intenciones de Siembra (RF06):** Módulo de planificación que permite a los productores proyectar sus cultivos por temporada, facilitando el análisis estadístico por zonas geográficas.
* **Logística y Flotas:** Administración del catálogo de vehículos, asignación de rutas operativas para transportistas y seguimiento de las entregas en tiempo real.
